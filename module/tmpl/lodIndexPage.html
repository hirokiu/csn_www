Citizen Seismology Networkのデータセット

Raspberry Piで構築した地震計から集約した観測波形、観測点情報、 および過去のデータ表示ページを公開しています。

現在の状態: Raspberry Pi地震計からのリアルタイム集約機能は現在停止しています。 これまでに公開した観測データと表示ページは引き続き参照できます。

Citizen Seismology Network datasets

This project publishes waveforms and station information collected from seismometers built with Raspberry Pi computers, together with archived data viewers.

Current status: Real-time aggregation from Raspberry Pi seismometers is currently unavailable. Previously published observations and dataset pages remain accessible.

  • Observation stations
  • CSN station map
  • Archived waveform viewer
  • Waveform selection

LOD applications

Regional seismic observation search

Searches observation stations and hypocenters by region, year, and intensity and displays them on a map.

Ontology query builder

A reserved deployment path for visualizing classes and properties as a node-edge graph and building SPARQL from selections.
